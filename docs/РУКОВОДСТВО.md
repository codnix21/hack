# Руководство пользователя

## Вход

1. Откройте http://localhost:3000
2. Войдите под пользователем или администратором, либо выберите «Продолжить как гость».

Гость может открывать демо-проекты и каталог, но не сохраняет изменения в общие данные.

## Типовой сценарий

1. **Создать проект** или открыть демонстрационный (склад / аэропорт / медицина).
2. **Параметры объекта** — заполнить или импортировать CSV/Excel.
3. **Подбор** — запустить подбор решений.
4. **Сравнение** — сравнить выбранные карточки.
5. **Экономика** — рассчитать CAPEX, OPEX, TCO, ROI, окупаемость; при необходимости — «что если».
6. **Визуализация** — демонстрационная 2D-схема маршрутов.
7. **Результаты / экспорт** — скачать PDF или Excel.

## Каталог решений

- Поиск по названию, компании, сценарию.
- Фильтры: происхождение, тип, отрасль, регион, цена и др.
- Пагинация: 10 / 20 / 50 записей на страницу.
- Бейджи происхождения: **Исходные материалы** / **Демонстрационные данные**.

Если характеристика отсутствует в материалах, на карточке показывается:  
«Нет данных в исходных материалах».

## Подбор

Статусы:

| Статус | Смысл |
|--------|--------|
| Подходит | Проверенные условия выполнены |
| Требует проверки | Не хватает данных или нужна экспертная оценка |
| Не подходит | Обязательные условия не выполнены |

Отсутствие ТТХ в исходных материалах **не** переводит решение в «Не подходит» автоматически — используется «Требует проверки».

## Экономика

Показатели:

- **CAPEX** — первоначальные затраты;
- **OPEX** — эксплуатационные затраты в год;
- **TCO** — совокупная стоимость владения;
- **ROI** — возврат инвестиций;
- **Срок окупаемости** — ориентировочный период возврата.

Сценарии: без роботизации, покупка оборудования, роботы как услуга (RaaS).

Раздел «Как рассчитано» показывает формулы и пояснения.  
«Сбросить изменения» возвращает what-if к базовым допущениям.

## Визуализация

Это **демонстрационная 2D-схема**, не точная карта объекта.

Управление: Запустить / Пауза / Сбросить, скорость 0,5× / 1× / 2×.  
На схеме: зоны, маршруты, роботы (R1…), загрузка / выгрузка / зарядка, легенда и лента событий.

## Экспорт

В шапке проекта:

- **Экспорт PDF** — титул, резюме, параметры, решения, экономика, допущения, источники;
- **Экспорт Excel** — отдельные листы отчёта (включая «Что если»).

Перед скачиванием: «Формирование отчёта…».  
При успехе: «Отчёт успешно сформирован».

## Демонстрационные проекты

1. Автоматизация склада  
2. Автоматизация аэропортового объекта  
3. Роботизация медицинского учреждения  

Параметры берутся из датасетов хакатона. В интерфейсе явно указано: «Демонстрационный проект».
