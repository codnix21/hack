# Статус соответствия ТЗ и ограничения

Дата актуализации: сентябрь 2026. Статус: **Release Candidate**.

## Сводка по требованиям

| Статус | Количество | Смысл |
|--------|------------|--------|
| Реализовано | 24 | Есть в продукте |
| Частично | 4 | Есть, но с оговоркой |
| Не реализовано | 2 | Сознательно не делалось |
| Ограничение данных | 1 | Мешает полнота исходных CSV |

## Реализовано

- аутентификация и роли (admin / user / guest);
- каталог с provenance, фильтрами и пагинацией;
- параметры объектов из датасетов;
- подбор с объяснениями и статусами;
- сравнение решений;
- экономика (CAPEX, OPEX, TCO, ROI, окупаемость, RaaS);
- what-if и чувствительность;
- три демо-проекта;
- демонстрационная 2D-визуализация;
- экспорт PDF/Excel;
- админка и импорт материалов;
- тесты (pytest, Vitest, Playwright) и Docker.

## Частично

1. **Полные ТТХ в карточках** — в CSV нет скорости, навигации, типа пола и т.п. для всех записей; UI честно пишет «Нет данных…», DOCX обогащает только сопоставленных.
2. **Подбор по полным ТТХ** — опирается на доступные поля; пропуски → «Требует проверки».
3. **DOCX-обогащение** — не создаёт роботов для несопоставленных имён (PuduBot 2).
4. **Допущения экономики** — амортизация / часть ставок задаются моделью команды, не файлом source.

## Не реализовано

1. **Отдельные полные модели кредит / лизинг** — по «Дополнениям» оставлены на усмотрение команды; в продукте не выделены.
2. **Парсинг PDF-каталога внедрения (~91 стр.) в БД** — не выполняется: дублирует CSV, тяжёлый layout/OCR.

## Известные ограничения (обязательно озвучивать на демо)

1. CSV без полного набора ТТХ.
2. DOCX обогащает только matched-решения.
3. PuduBot 2 не сопоставлен с каталогом.
4. PDF-каталог внедрения не импортируется.
5. Экономика при отсутствии source-чисел — ввод пользователя / допущения (явно помечены).
6. 2D-визуализация демонстрационная, не CAD/BIM.
7. Кредит/лизинг как отдельные модели отсутствуют.

## Принцип честности данных

- не придумывать ТТХ;
- не подменять source демо-данными без маркировки;
- отсутствующее поле → «Нет данных в исходных материалах»;
- допущение модели → «Допущение».
