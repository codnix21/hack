# Запуск платформы

## Docker (рекомендуется)

Из корня репозитория:

```bash
docker compose down
docker compose up -d --build
```

Сервисы:

| Сервис | Порт (по умолчанию) | Описание |
|--------|---------------------|----------|
| frontend | `127.0.0.1:8910` | UI (nginx), для FastPanel upstream |
| backend | `127.0.0.1:8010` | FastAPI (снаружи не обязателен, `/api` через frontend) |
| db | `127.0.0.1:5435` | PostgreSQL |

На сервере с доменом `bas.netcorehub.ru`:

```bash
cp .env.example .env   # задать пароли и SECRET_KEY
docker compose up -d --build
```

В nginx FastPanel:

```nginx
upstream bas.netcorehub.ru18 {
    server 127.0.0.1:8910;
}
```

Порты переопределяются через `.env` (`FRONTEND_PORT`, `BACKEND_PORT`, `POSTGRES_PORT`).

При старте backend выполняет миграции и начальное наполнение (seed).  
Импорт исходных материалов нужно запустить вручную из админки (см. [АДМИНИСТРИРОВАНИЕ.md](./АДМИНИСТРИРОВАНИЕ.md)).

Проверка:

```bash
curl http://localhost:8000/health
```

Остановка:

```bash
docker compose down
```

Полный сброс БД (данные будут удалены):

```bash
docker compose down -v
docker compose up -d --build
```

## Локальный запуск без Docker

### Backend

Требуется Python 3.11+.

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:DATABASE_URL="sqlite:///./robot.db"
uvicorn app.main:app --reload --port 8000
```

API: http://127.0.0.1:8000/api  
Документация API: http://127.0.0.1:8000/docs

### Frontend

Требуется Node.js 20+.

```powershell
cd frontend
npm install
$env:VITE_API_URL="http://127.0.0.1:8000/api"
npm run dev
```

UI: http://127.0.0.1:5173

## Тесты

```powershell
# Backend
cd backend
$env:DATABASE_URL="sqlite:///./robot_test.db"
pytest tests -q

# Frontend
cd frontend
npm test
npm run build

# E2E (нужен запущенный стек на :3000)
npm run test:e2e
```

## Типичные проблемы

| Симптом | Что проверить |
|---------|----------------|
| UI не открывается | `docker compose ps`, порт 3000 |
| 404 на `/api/...` | backend на 8000, nginx proxy |
| Пустой каталог | Админ → Импорт материалов → каталог CSV |
| Нет демо-проектов | Импорт датасетов XLSX |
| Ошибка БД при старте | подождать health Postgres, смотреть логи `docker compose logs backend` |
