# Исходные материалы

Все материалы хакатона хранятся в каталоге **`data/sources/`**.  
Приложение **не изменяет** эти файлы (только чтение).

Символическая ссылка / junction `source/` → `data/sources/` может использоваться для удобства; рабочий путь в коде и Docker — `data/sources`.

## Состав

| Файл | Назначение в платформе |
|------|------------------------|
| `catalog_export_v4.csv` | Основной каталог решений (source) |
| `Датасеты_хакатон.xlsx` | Параметры объектов: склад, аэропорт, медучреждение |
| `Примеры_решений_типы_объектов.docx` | Примеры ТТХ и ссылок для обогащения карточек |
| `1. ФЦ БАС.pdf` | ТЗ платформы (требования) |
| `Дополнения для участников.pdf` | Уточнения ТЗ, роли, экономика |
| PDF-каталог внедрения (~91 стр.) | Справочный материал; **в БД не импортируется** (дублирует CSV) |

## Что загружается в систему

### Каталог CSV

- уникальные решения с происхождением `source`;
- поля названия, компании, типа, сценария, региона, отрасли, цены и др.;
- provenance: файл, строка, статус источника.

Типичный итог: **187** решений из исходных материалов (+ отдельно демонстрационные seed-записи).

### Датасеты XLSX

- схемы параметров трёх типов объектов;
- порядка **138** параметров суммарно;
- обновление демонстрационных проектов.

### DOCX

- поиск блоков ТТХ и URL;
- сопоставление с уже существующими роботами по названию;
- запись в `raw_data.docx_enrichment`, при пустых полях — payload / URL;
- несоздаёт новые записи «с нуля» для несопоставленных имён.

Типичный итог: найдено ~9 примеров, сопоставлено ~7, не сопоставлено: **PuduBot 2**.

## Происхождение данных в UI

| Метка | Смысл |
|-------|--------|
| Исходные материалы | Данные из `data/sources/` |
| Демонстрационные данные | Seed / демо для показа возможностей |
| Нет данных в исходных материалах | Поле пустое в материалах |
| Допущение | Значение модели расчёта / норматива |

Демонстрационные данные **не являются заменой** исходных материалов.

## Шаблоны и примеры

- `data/templates/` — шаблоны параметров объекта для импорта в проект;
- `data/catalog/sample_catalog.csv` — пример для универсального импорта каталога.
