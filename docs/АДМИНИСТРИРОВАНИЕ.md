# Администрирование

Доступно только роли **администратор**.

## Разделы админки

- пользователи;
- проекты;
- каталог;
- справочники (производители, типы объектов, типы решений, источники);
- нормативы / допущения;
- импорт каталога (универсальный CSV/XLSX);
- **импорт материалов** (исходные файлы хакатона);
- журнал аудита.

## Импорт материалов проекта

Путь: **Администрирование → Импорт материалов**.

Файлы читаются из `data/sources/` (в Docker — `/data/sources`). Оригиналы не изменяются.

| Действие | Файл | Результат |
|----------|------|-----------|
| Импортировать каталог | `catalog_export_v4.csv` | Роботы с `data_origin=source`, provenance |
| Импортировать датасеты | `Датасеты_хакатон.xlsx` | Схемы параметров, обновление демо-проектов |
| Обогатить из DOCX | `Примеры_решений_типы_объектов.docx` | ТТХ/URL у сопоставленных карточек |

После операции показывается сводка: обработано / добавлено / обновлено / пропущено / ошибок.  
Несопоставленные примеры DOCX (например, PuduBot 2) не скрываются.

### Ограничение размера загрузки

Для файлов, загружаемых через форму: максимум **10 МБ**.  
При превышении: «Файл слишком большой. Максимальный размер — 10 МБ.»

## История импортов

Таблица партий:

- файл, тип, дата, статус;
- строк, добавлено, обновлено, пропущено, ошибок;
- кнопка **Подробнее** — список ошибок по строкам/полям.

## Универсальный импорт каталога

Раздел «Импорт каталога»:

1. выбрать CSV/XLSX;
2. предпросмотр и сопоставление колонок;
3. подтверждение импорта.

Пример файла: `data/catalog/sample_catalog.csv`.

## Производные отчёты

После DOCX-импорта в `data/imported/` могут появиться:

- `docx_mapping.md`
- `docx_mapping.json`

Это служебные отчёты, не исходные материалы.
