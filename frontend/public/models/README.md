# 3D-модели NETCORE (GLB / glTF)

Каталог статических моделей для WebGL-сцены. Blender **не** требуется во время работы приложения.

## Соглашение об именах

| Файл | Назначение |
|------|------------|
| `amr.glb` | Корпус AMR (опционально). Пока **не** подключается в runtime: без файла SPA отдаёт HTML и ломает сцену. Роботы рисуются процедурно. |
| `rack.glb` | Стеллаж (зарезервировано; сейчас процедурная геометрия). |

Масштаб экспорта: **1 единица Blender = 1 метр**. Ориентация: +Y вверх, робот «носом» к −Z (как в Three.js после `useGLTF`).

## Экспорт из Blender

1. Модель в реальных метрах, origin у центра основания на полу.
2. File → Export → glTF 2.0 (`.glb`).
3. Format: glTF Binary; Apply Modifiers; +Y Up.
4. Положить файл в этот каталог и пересобрать frontend (`npm run build` / `build:demo`).

Подробнее: `docs/NETCORE_3D_PLANNING_INTEGRATION.md`.
