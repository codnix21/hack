# Платформа подбора роботизированных решений

Веб-платформа для подбора роботизированных решений, расчёта экономического эффекта и демонстрационной 2D-визуализации работы роботов на объекте.

Интерфейс полностью на русском языке.

## Возможности

- каталог решений (исходные материалы + демонстрационные данные);
- проекты по типам объектов: склад, аэропорт, медицинское учреждение;
- подбор с объяснениями (подходит / требует проверки / не подходит);
- экономика: CAPEX, OPEX, TCO, ROI, срок окупаемости, сценарии покупки и RaaS;
- анализ «что если» и чувствительность;
- демонстрационная 2D-схема движения роботов;
- экспорт отчётов в PDF и Excel;
- роли: гость, пользователь, администратор.

## Быстрый старт

```bash
docker compose up -d --build
```

| Адрес | Назначение |
|-------|------------|
| http://127.0.0.1:8910 | Интерфейс (Docker) |
| http://127.0.0.1:8010/api | API (отладка) |
| http://127.0.0.1:8010/docs | OpenAPI |
| http://127.0.0.1:8010/health | Проверка работоспособности |
| https://bas.netcorehub.ru | Прод (FastPanel → :8910) |

После старта: **Администрирование → Импорт материалов** (каталог CSV, датасеты XLSX, обогащение DOCX).

## Структура репозитория

```
backend/           API (FastAPI), расчёты, импорт, экспорт
frontend/          UI (React + Vite)
data/sources/      исходные материалы хакатона (только чтение)
data/catalog/      пример CSV для универсального импорта
data/templates/    шаблоны параметров объекта
data/imported/     производные отчёты импорта (генерируются)
docs/              документация на русском
docker-compose.yml
```

## Важно

- Исходные материалы лежат только в `data/sources/` и не редактируются приложением.
- Демонстрационные данные **не заменяют** исходные материалы.
- 2D-визуализация — **демонстрационная схема**, не цифровой двойник объекта.
- Типичные счётчики после импорта: **187** решений из исходных материалов, **36** демонстрационных, **138** параметров объектов (значения в UI берутся из API).
